## 📁 Featured Projects

### 🪪 [MemberFlow: SaaS Membership Management System](https://github.com/fuad665/Membership-Management-System)
*A premium SaaS dashboard built for administrators to manage organization departments and issue digital verification credentials.*
* **Core Tech**: Next.js 16 (App Router), Tailwind CSS v4, Axios, Supabase (PostgreSQL)
* **Key Features**: 
  * Full administrative signups, logins, and session handling.
  * Active metric analytical counters and status distributions.
  * Double-sided digital badges with offline-scannable QR verification keys and pdf rendering.
  * Public secure validation portal checks (`/verify/[id]`).
* **Links**: [GitHub Repository](https://github.com/fuad665/Membership-Management-System) | [Live Demo URL](https://membership-management-system-rho.vercel.app/)

### 📈 [AI-Driven Market Analytics Dashboard](https://github.com/fuad665/market-analytics)
*An intelligent data analysis project that aggregates market prices, performs trend modeling, and renders real-time forecast graphs.*
* **Core Tech**: Python, Pandas, FastAPI, React, Chart.js
* **Key Features**:
  * Automated data collection via finance APIs.
  * Predictive price-trend algorithms running on Python server.
  * Sleek glassmorphism React analytics view with dark/light themes.
